# Experiment Notes

This folder is for what you won't find in any article: **the results of your own experiments and
measurements.** See [How to learn](../how-to-learn.md).

File name format: `YYYY-MM-DD-short-title.md`

```markdown
# Title

- **Related stage:** 04 JavaScript
- **Question:** ...
- **Hypothesis:** ...
- **Experiment:** code / steps / link
- **Result:** numbers, screenshots
- **Conclusion & surprises:** ...
```
